## 头脑风暴决策

1. 核心问题已确认：没有特定工作流也能统一管理项目和任务；有工作流时按项目读取有来源的进度线索。项目身份、目录、工作流与实际完成事实分离。
2. 采用已有 Python 模块和 SQLite/原生页面增量，先支持少量明确的内置来源，不造任意代码插件/正则引擎，不重写整个面板。
3. 项目使用稳定 ID，用户可添加/修改/归档登记及重新绑定目录；目录变化不改项目 ID、不丢任务/人工记录。允许同项目显式绑定多个工作目录，以覆盖 worktree；不把同一远程仓库或文件名作为身份。
4. 人工记录与工作台任务是独立可用的基础。现有 workflow-for-coding 文档规则只是可选预设；再提供受限的用户指定文本/结构化进度来源，读取失败、未配置、未识别和真实 0 分开。文档 PASS/mtime 不自动完成项目或覆盖人工状态。
5. 去除项目管理关键链上的本机用户名/目录假设，使用当前用户配置与显式目录/来源配置。默认新用户工作台为空；现有数据通过明确、非破坏的兼容/导入路径保留。不能把开发者个人登记/启动器当成所有人的默认数据。
6. 必要存储/配置演进以有界本机普通事务、校验、备份和明确错误为深度，不引入分布式事务或事件溯源平台。旧 JSON/SQLite/garden/执行账本保持所有权；不移动或清理旧运行，不对现有服务执行重启/接管。
7. 调研后的技术收敛：每用户空 profile，宿主来源小型版本化配置，项目/目录/人工历史/任务/用量以当前 profile 的管理 SQLite 为权威。Codex 元数据库必须显式配置；默认不装配旧 SSH、个人启动器、garden、ExecutionService。旧库与已有服务保留，另端口须明确选择，不自动接管。

## 完整实现基线

### 1. 目标锁

- G1：其他本机用户无需修改源码、无需 Git 或指定工作流即可登记项目、绑定目录和管理任务。稳定项目 ID 与本机路径分开，目录迁移/多工作目录不破坏旧关联；当前用户已有项目及数据保留。
- G2：统一展示后续开发进度，保留人工状态/进度、任务状态统计与可选文档观察各自来源。支持现有工作流预设和受限的通用进度输入；缺失/错误/未知可辨，评审 PASS 不能被当成项目完成。
- G3：在真实页面提供项目管理、目录/进度来源设置及进度查看操作；配置可持久化并在重启/重新读取后有效，关键会话元数据来源不再写死用户名。用隔离实际存储/HTTP、浏览器和 fresh review 证明兼容，不以静态卡片或 fixture 推导真实 Agent/Orca 能力。

### 2. 反目标

- 不为兼容要求用户安装本人的工作流或在所有项目写同一种文档；不使用任意项目代码插件、AI 自动判完成、进程活着/文档 mtime 估百分比。
- 不覆盖旧手工状态/任务/运行/小院/源文件；不全库重写、同时迁移 HTTP/框架、无限目录扫描或未经配置读取私人正文。
- 不借项目登记改变执行权限，不自动 Agent 派发、账号/额度操作、Orca 安装启动、公网监听；旧 M3 与 P1-B 阻断保持。

### 3. 风险边界

单机可信用户、loopback/Host/Origin/客户端/CSRF 原合同保持。项目路径与进度文件由用户显式配置，读取有界并校验范围；不执行被读取文件。个人配置与共享源码分开；导入/兼容须保留旧文件、稳定 ID、失败证据和撤销路径，不能默默截断或覆盖冲突数据。

当前增量采用 hlplan D1–D4：多个显式目录只参与观察，既有执行合同仍只认唯一主目录和原 context_hash；嵌套观察按最长匹配，等长冲突显示歧义。人工整体进度、任务统计、文档观察并列，不相互写入。普通文本/预设/版本化 JSON 的来源失败只能影响观察，不能将 unknown 变为人工 0。

真实现有服务/用户库不能被 fixture 测试修改或接管。root可启动自己的隔离预览，外部额度/资讯/会话来源使用隔离替身以避免账号/正文读取和模型费用。本轮只保证受测 Windows 单机入口，不将词法或窄屏证据升级为跨设备/真实平台验收。

### 4. 验证责任

- researcher：读取真实相关代码、测试、配置和官方参考，不读私人正文，写事实、U 点与最小证据。
- architecture/lwplan：完整消费基线；明确数据所有权、兼容/错误/备份回退、API/GUI和 impl-safe vs root承接测试；不得把未决设计留给实施。
- impl：源码、纯 fixture、语法、隔离存储/协议自证，保留退出码与完整失败；不运行浏览器或旧服务/真实 Agent。
- coordinator：独立复跑、原文件范围与旧数据保护检查，自己拥有的隔离 HTTP/浏览器桌面与320/375/768px交互、截图。证据放 work/project-progress-compat-20261014；缺证据不得报完成。
- fresh reviewer：审最终实际 diff、计划、数据/来源/执行边界及原始证据；修改后重新验证并换 fresh reviewer。正式 Gate 按技能保持。
