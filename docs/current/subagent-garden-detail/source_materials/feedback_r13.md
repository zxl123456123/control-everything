# R13 用户原话

> 给我看起来的主界面要清晰直观，然后具体点进去后可以展示一些具体的详细信息，比如负责做什么的。对话信息之类的，以及他们的工作进度情况。还有可以简单标识一下他们在视图理的角色信息，然后工作空间的一些控制，是让它自由去操作，不是有我来控制它的动作，这些都是你来预定义即可。
