## 未回答

无。用户已将场景行为的具体选择交给实施者预定义；以现有默认自由巡游和仅代表展示的动画为准。对话展示选择为当前本机能可靠读取的子agent公开发言片段，并清楚标注覆盖范围；不将内部提示、工具输出或推理内容当成对话。

## 已回答及头脑风暴决策

1. 主界面先说明同一主会话的伙伴数、任务阶段、待处理结果；角色卡只保留名字、角色、负责事项与当前已证实阶段，云朵仍为完成摘要。详细身份、收据和对话在选中角色后渐进展开。
2. 角色详情呈现实际任务标题、角色职责/已注册能力、可核验的交接节点和时间，以及按需读取的最近公开发言。无法读到时说明不可用或没有可展示发言，不填充伪对话。
3. 主会话根仍由进程原生父链决定；发言读取必须先确认所选 actor 已登记且与当前 root 相同，再查只读本机索引中该 actor 的精确 rollout 路径，仅取有限公开 assistant commentary/final_answer 文本，拒绝外来路径与跨域请求。默认主页不预取对话。
4. 小院场景维持现有 3D/像素/文字回退与自主巡游；隐藏操纵机器人巡游、动画和相机的按钮，保留点选角色以及必要的查看模式切换。移动继续只作为装饰，不冒充工作或完成状态。
5. W3C WAI Disclosure/Status 的成熟模式用于详情展开与状态通知；Codex 官方 app-server 的 thread/read/turns/list 提供可参考的读模型，但当前本地网页无经验证的 app-server 连接，采用有界只读原生路径，不加入新服务或任意命令。若原生格式/路径不符则显示不可用。

## 完整实现基线

### 1. 目标锁

- **G13.1** 360/574/1024 宽的主界面能直接看出各伙伴角色、负责事项、实际任务节点和需关注的结果；选中后有清楚的职责、时间线、产物/收据及可读发言详情。键盘与长中文可用。
- **G13.2** 对话只按需显示当前 root 已登记子agent的原生公开发言；不跨主会话、不读取 developer/system/user/tool/reasoning 或不明格式，不把摘录称作完整对话。
- **G13.3** 小院机器人自主活动，用户不承担路径、巡游、动画控制；场景仍可选择角色，原 3D/像素/文字回退及 R12 收据链不退化。

### 2. 反目标

- **N13.1** 禁止从动画、`updated_at`、回合结束推断实时工作或任务完成，禁止虚构百分比、消息、回复或进度。
- **N13.2** 禁止外部 caller/root/path 参数、目录扫描、跨主会话读取、加载整份 rollout 到网页、展示私有角色文本或工具结果；仅有限白名单公开发言。
- **N13.3** 禁止修改 R12 账本事务、旧远端观察与终端控制语义，或降低 3D 原画质/角色数量以换取布局/性能。

### 3. 风险边界

原生 SQLite 的 `rollout_path` 与 JSONL 记录类型属于当前本机版本实现细节，不是稳定公开 API；缺行、schema 漂移、文件路径逃逸、读取/解析预算耗尽均关闭对话展示。可信边界仍为当前 OS 账户、本机 loopback root 网关，不承诺抵御同账户恶意改 DB/环境。所谓“进度”仅是账本业务阶段，不能显示子agent此刻是否在生成文字。实际 IAB 前台帧率仍需另测，受控 Edge 不能代替。
公开 assistant 发言本身可能复述敏感资料；白名单只能保证不直接转发内部记录类型，不能做内容级脱敏承诺。摘录默认只在用户点开角色时读取并限制条数、长度，前端按纯文本呈现。Windows 路径可能混用普通盘符与 `\\?\` 扩展形式，必须统一规范化后核对固定 sessions 根和文件名。

### 4. 验证责任

- 实施者：临时同根/跨根数据库与 JSONL 固定样本，检验白名单、路径、预算、不同阶段与文字回退；运行全 Python/浏览器回归，并保存完整输出和失败。
- coordinator：核对真实当前原生 child 的只读摘录与实际 8766 GET、资源字节、360/574/1024 真页面、旧画质连续性能；不足时仅称未验证。
- 独立审查者：在最终产品字节上复看源、测试和真实证据，给出协议与业务双结论；修改后重新审查。
